# HackIndia-Spark-5-2025-Hack-Horizon
This project is a dynamic, full-stack decentralized application (dApp) where students have harnessed the power of blockchain technology to create a fully functional NFT minting platform. Users can easily mint NFTs on the Ethereum blockchain, with a Solidity smart contract ensuring secure and transparent transactions throughout.

# Tech Stack
- **Frontend**: React (provides a smooth, dynamic user interface for a seamless experience)

- **Blockchain**: Ethereum (powers the minting of NFTs through Solidity smart contracts)

- **Smart Contract Language**: Solidity (ensures secure and transparent transactions)

- **Storage**: IPFS (InterPlanetary File System) for decentralized and censorship-resistant storage of NFT metadata and images

- **Wallet Integration**: MetaMask (enables users to connect their wallets and interact directly with the smart contract)

# Features
- **NFT Minting**: Users can mint NFTs on the Ethereum blockchain through an easy-to-use interface.

- **MetaMask Integration**: Effortless connection of MetaMask wallets to the platform for seamless interaction with the smart contract.

- **Decentralized Storage**: Utilizes IPFS to store NFT metadata and images in a decentralized and tamper-proof way.

- **Secure Transactions**: All NFT transactions are secured by the Ethereum blockchain, ensuring transparency and immutability.
